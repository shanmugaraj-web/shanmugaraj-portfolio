# Shanmugaraj Y — Portfolio

Premium personal portfolio for a Digital Marketer and AI Search Strategist, built with Next.js, TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Performance screenshots included in this repository have been sanitized to remove identifying account, client and property information.
